# 05-登录崩溃修复-2026-07-26

## 问题描述

用户登录时报错：

```
Cannot read properties of undefined (reading 'elements')
```

登录请求本身成功（后端 `/api/users/login` 返回 200），但前端在隐藏登录弹窗时崩溃，导致弹窗不关闭并抛出异常。`handleCreateAccount`（创建账户）调用 `handleLogin()`，因此创建账户流程同样崩溃。

## 根因

`static/js/UI.js` 中的 `hideLoginModal(appState)` 函数签名要求传入 `appState`，函数体内访问 `appState.elements.loginModal`：

```js
// UI.js:257
export function hideLoginModal(appState) {
    appState.elements.loginModal.classList.add('hidden');
}
```

但 `static/js/index.js` 的 `handleLogin` 函数在登录成功后调用时**漏传了 `appState` 参数**：

```js
// index.js:2009 (修复前)
hideLoginModal();   // appState 为 undefined → undefined.elements 崩溃
```

函数内 `appState` 形参为 `undefined`，访问 `undefined.elements` 抛出 `Cannot read properties of undefined (reading 'elements')`。

## 模式对比

同文件内其他调用点均正确传参，唯独 `handleLogin` 内这一处漏传：

| 行号 | 调用 | 状态 |
|------|------|------|
| 1797 | `hideLoginModal(appState)` | ✓ 正确 |
| 1801 | `hideLoginModal(appState)` | ✓ 正确 |
| **2009** | `hideLoginModal()` | ✗ BUG（已修复） |
| 2049 | `handleLogin()`（创建账户间接触发） | 连带崩溃 |

## 同类 bug

排查中发现 `index.js:319` 的 `handleSidebarCollapse()` 同样漏传 `appState`（`UI.js:32` 的同名函数要求该参数）。此处在 podcast 列表项点击回调中，当侧栏处于折叠状态时触发，会导致同样的 `undefined.elements` 崩溃。虽不在登录流程，但属同一根因模式，一并修复。

## 修复

`static/js/index.js`，共 2 行改动：

```diff
@@ -316,7 +316,7 @@
                 if (sidebar.classList.contains('collapsed')) {
-                    handleSidebarCollapse();
+                    handleSidebarCollapse(appState);
                     playerDiv.classList.add('hidden');
                 }

@@ -2006,7 +2006,7 @@
             updateCurrentUserUI(appState);
-            hideLoginModal();
+            hideLoginModal(appState);
             showNotification(t('toast.login_success'), 'success');
```

## 验证

1. **git diff 确认**：仅 2 行改动，surgical，未触碰其他代码。
2. **同类排查**：grep 所有从 `UI.js` 导入的需要 `appState` 的函数（`hideLoginModal`/`showLoginModal`/`hideBookModal`/`showBookModal`/`hideFileModal`/`showFileModal`/`updateCurrentUserUI`/`resetBookView`/`resetPdfView`/`checkTextContent`/`updateTextChunkReader`/`renderNotifications`/`updateVoices`/`updatePlayerUI`/`updateCurrentPage`/`handleSidebarCollapse`）的空参数调用 `funcName()`，结果为空——无其他漏传。
3. **行为验证**：登录成功后 `hideLoginModal(appState)` 正确隐藏弹窗，流程继续执行 `showNotification` 与 `fetchAndRenderOnlineBooks`/`fetchAndRenderPodcasts`，不再崩溃。

## 影响范围

- 登录流程：修复登录成功后弹窗不关闭 + 控制台报错
- 创建账户流程：修复间接触发 `handleLogin` 的连带崩溃
- Podcast 播放：修复侧栏折叠状态下点击 podcast 项的崩溃
